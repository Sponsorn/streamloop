Welcome to StreamLoop

StreamLoop plays YouTube playlists to Twitch around the clock and recovers on its own when a video fails.

Setup takes four steps:
  1. Add your YouTube playlists
  2. Enter your Twitch stream key
  3. Optional: Discord alerts and Windows autostart
  4. Check that the stream goes live

YouTube Playlists

Add the playlists you want to stream. The first one plays; you can switch later from the dashboard.

Where to find a playlist ID
youtube.com/playlist?list=PLxxxxxxxxxxxxxxxx

Paste the whole playlist URL, or just the part after list=.

Twitch Stream

StreamLoop sends the stream straight to Twitch.

Where to find your stream key
  1. Open the Twitch Creator Dashboard
  2. Go to Settings, then Stream
  3. Click Copy next to Primary Stream key and paste it below
Stored encrypted on this PC. The dashboard never shows it again.

How do I create a Discord webhook?
  1. Open your Discord server and go to Server Settings
  2. Click Integrations, then Webhooks
  3. Click New Webhook
  4. Choose a channel for notifications and give it a name
  5. Click Copy Webhook URL and paste it above

How do I get Twitch API credentials?
  1. Go to dev.twitch.tv/console/apps and log in with the Twitch account you stream from
  2. Click Register Your Application
  3. Fill in the form:
    • Name: anything you like (e.g. StreamLoop)
    • OAuth Redirect URLs: copy the value below, paste it in, and click Add. Twitch requires it; StreamLoop doesn't use it.
      https://localhost
    • Category: select Application Integration
    • Client Type: select Confidential
  4. Click Create
  5. Back in the app list, click Manage on your new app.
  6. Copy the Client ID and paste it below
  7. Click New Secret, confirm, then copy the Client Secret and paste it below. Twitch shows it only once.
